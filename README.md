# 一筆書きメーカー

写真・イラスト・文章から、**途切れない一本の線**で描いた絵（一筆書き / ワンラインドローイング）を生成する Web サービスです。

## できること

| 入力 | 処理 |
| --- | --- |
| 写真・イラスト | ドロップ / 選択 / 貼り付けた画像を、ブラウザ内だけで一筆書きに変換 |
| 文字 | 入力した文字を指定の書体で描き、その形を一筆書きに |
| 文章から絵 | 「自転車に乗る猫」のような文章から AI（Claude）が線画の下絵（SVG）を作り、それを一筆書きに |

- スタイル: **輪郭**（写真向き）/ **線画**（イラスト・文字向き）/ **陰影**（点描風）
- **線を交差させない**（既定で有効）: 線同士が一度も交わらない一筆書きにします
- **手書き感**: ゆっくりした手のゆらぎと、筆圧による太さの強弱（曲がりは太く、速い直線と描き始め・終わりは細く）
- **線どうしのすき間**: 交差しそうなほど近づいた線を、指定のすき間まで押し広げます（離しすぎないよう元の位置へ弱く引き戻す）
- 細かさ・しきい値・なめらかさ・線の太さ・色・背景（透明可）を調整可能
- 描く様子のアニメーション再生、SVG / PNG で保存

## 仕組み

```
画像 ──▶ 濃淡マップ ──▶ 描く点を配置 ──▶ 全点を1本でつなぐ ──▶ 曲線化して SVG
          (輪郭: Sobel+非最大値抑制   (ポアソンディスク風     (巡回セールスマン問題の近似:
           線画: 2値化+細線化         サンプリング)            最近傍法 + 2-opt)
           陰影: 暗さ=点の密度)
```

1. **解析**: 画像を長辺 640px に縮小し、モードに応じて「線を引くべき画素」を求めます。背景が暗い画像は自動で反転します。
2. **点の配置**: 候補画素から、一定の間隔を保つように点を選びます。点の数が「細かさ」に近づくよう間隔を自動調整します。
3. **経路**: すべての点を一度ずつ通る短い経路を、最近傍法で作ってから近傍リスト付き 2-opt で改善します。最後に一番長い区間を切って始点・終点にします。
4. **交差の解消**: 交わっている 2 辺 (A,B), (C,D) を (A,C), (B,D) につなぎ替えます（間の区間は逆向きになる）。つなぎ替えるたびに経路は必ず短くなるので、交差がなくなるまで繰り返しても必ず終わります。交差の検出には線分が通るグリッドセルだけを調べる空間索引を使います。
5. **手描きの仕上げ**（`public/lib/handdrawn.js`）
   - 線を等間隔の細かい点に打ち直し、角を丸めてから、弧長に沿ったなめらかなノイズで左右にゆらします。
   - 経路上では離れているのに空間的に近い点どうしを、「すき間 + 線の太さ」まで押し広げます。押すのは足りない分だけで、押す量は前後になめらかに広げ、押されていない部分は元の位置へ少しずつ戻します（最大でも目標間隔の 2 倍までしか動かさない）。
   - どの段階でも、動かした結果交差が生じたら、関わった点とその前後を元の位置へなめらかに戻すので、交差しないことは保たれます。
6. **出力**: 筆圧ありは太さの変わる塗りつぶしの線、なしは一定の太さの線として 1 本の `<path>` にします。描画アニメーションは中心線のマスクで少しずつ見せます。

重い計算は Web Worker で行うため、操作中も画面は固まりません。コアは `public/lib/onestroke.js`（依存なし）にまとまっています。

## 動かし方

Node.js 20 以上が必要です。

```bash
npm install
npm start            # http://localhost:3000
```

「文章から絵」を使う場合は Anthropic の API キーを設定して起動します。

```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```

写真・文字モードは API キーなしで動き、`public/` を静的ホスティング（GitHub Pages など）に置くだけでも使えます。

### 環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | 待ち受けポート |
| `ANTHROPIC_API_KEY` | — | 「文章から絵」に必要 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 下絵を描くモデル |
| `CLAUDE_EFFORT` | `medium` | 思考の深さ（`low` にすると速く安く、`high` にすると丁寧に） |
| `RATE_LIMIT_PER_MIN` | `6` | 1 IP あたり 1 分間の「文章から絵」リクエスト上限 |

## プライバシー

写真・文字の処理はすべて利用者のブラウザ内で完結し、サーバーには送信されません。「文章から絵」だけが入力文をサーバー経由で Anthropic API に送ります。

## 開発

```bash
npm test
```

```
server.js               静的配信 + /api/text-to-svg（Claude で SVG 線画を生成）
public/index.html       画面
public/app.js           UI（入力の読み込み・設定・描画・保存）
public/worker.js        Web Worker（生成処理を別スレッドで実行）
public/lib/onestroke.js 一筆書き生成アルゴリズム（点の配置・経路・交差の解消）
public/lib/handdrawn.js 手描き風の仕上げ（ゆらぎ・すき間・筆圧）
test/                   node:test によるテスト
```
